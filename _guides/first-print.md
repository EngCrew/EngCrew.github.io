---
title: "First 3D print checklist"
date: 2026-11-07
tag: "3D printing"
summary: "Go from file to a print that actually sticks to the bed."
steps:
  - "Clean the build plate with isopropyl alcohol"
  - "Level the bed or run the printer's auto-levelling"
  - "Check your filament is dry and feeding smoothly"
  - "Orient the part so the flattest face is on the bed"
  - "Turn on supports only where overhangs need them"
  - "Add a brim if the part is tall or tends to warp"
  - "Preview the sliced layers before you print"
  - "Watch the first layer go down before walking away"
