# EngCrew website

Hey there EngCrew! This is the code for the EngCrew site. You don't need to touch any code to add content.

## Adding a blog post, guide or template

1. Go to **https://app.pagescms.org** and sign in with GitHub.
2. Open this repository.
3. Pick **Blog posts**, **Guides (checklists)** or **Templates** in the sidebar.
4. Click **Add an entry**, fill in the form, and click **Save**.
5. Wait about a minute, then refresh the site. Your post is live.

To edit something, click it in the list, change it, and Save. To hide a post without deleting it, tick **Hide from the site (draft)**.

## Tips

- **Newest first:** posts, guides and templates are sorted by their Date field.
- **Callout boxes:** in a blog post, use the quote button in the editor to make a highlighted box.
- **Images:** use the image button in the post editor. Uploads are saved in the `images` folder.
- **Linking to other pages on the site:** use links like `#templates`, `#guides` or `#blog`.

## Where things live

| What | Folder |
